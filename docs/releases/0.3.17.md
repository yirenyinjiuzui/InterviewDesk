# InterviewDesk v0.3.17

首个以 InterviewDesk 名义发布的 Windows x64 便携版。下载 InterviewDesk-0.3.17-win-x64-portable.exe 后可直接运行，应用沿用 MeetingCopilot 的本机资料目录。

- 面试持续答把紧接主问题的限定条件并入原题，为稍后的独立追问另开答案。简短应声不会单独触发回答。
- 阿里云实时转录使用压缩音频上传，改善双路输入出现积压时的定稿。合成对话三轮回放均得到两道独立答案。[回放条件和逐轮耗时](https://github.com/yirenyinjiuzui/InterviewDesk/blob/v0.3.17/modules/面试转录与持续答/回放验收.md)
- 提供面试材料与题库、双语阅读、笔试截图多模型回答、服务连接测试和快捷键配置。

可用 PowerShell 的 `Get-FileHash .\InterviewDesk-0.3.17-win-x64-portable.exe -Algorithm SHA256` 对照同页 SHA256SUMS.txt 校验下载。
